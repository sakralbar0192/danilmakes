Streaming XLSX pipeline

Идея из продакшена (PHP StreamingExporter): окно → dayVector → sparse write → discard. Без полной матрицы ячеек в памяти. НТ до рефакторинга: dual per_day ~152M peak / OOM.

Зачем НТ

Понять, нужно ли снижать память и время выгрузки — до рефакторинга гипотеза, после — подтверждение.

  • Как: ручные тяжёлые прогоны + PHP CLI loadtest / протоколы.
  • Что увидели: dual per_day с полной матрицей — порядка ~152M peak и OOM.
  • Решение: потоковая запись окнами вместо полной матрицы в памяти; acceptance loadtest + parity.
